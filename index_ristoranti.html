⚙️ Sincronizzazione

I ristoranti vengono salvati come file nel vostro repository GitHub, così restano sincronizzati tra i vostri dispositivi. Serve un token generato dal vostro account GitHub (nessun nuovo account da creare).

1. Su GitHub: foto profilo (in alto a destra) → Settings
2. In fondo al menu a sinistra → Developer settings
3. Personal access tokens → Fine-grained tokens → Generate new token
4. Repository access → Only select repositories → scegli il repository di quest'app
5. Permissions → Repository permissions → Contents: Read and write
6. Generate token, poi copialo e incollalo qui sotto (si vede una volta sola!)
